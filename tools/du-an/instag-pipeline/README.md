# instag-pipeline

Glass lab (tools/_shared/glass-lab) for blog/src/content/posts/du-an/nhan-vat-so/instag-tung-buoc.mdx.
Chapter 3 reads real Δμ statistics of the trained InsTaG model (tools/_shared/radiance/data/trained/instag/meta.json)
and the OpenFace signals of the same clip; chapter 5 lists held-out metrics of the trained SyncTalk and InsTaG models.
Chapters 1, 2 and 4 are small simulations of InsTaG's mechanisms (model.ts). The trained model is shown by tools/du-an/instag.
