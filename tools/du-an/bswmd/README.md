# BSWMD explainer

Native educational simulation for the BSWMD article. It shows how one candidate ECUC value is classified as `PASS`, `FAIL`, or `DEGRADED` depending on the available definition authority.

The tool is deterministic and does not parse, read, or write a real ARXML workspace. The production pipeline is explained in `blog/src/content/posts/du-an/agent-ky-thuat/bswmd.mdx` and the end-to-end transaction flow is covered by the SDVX Modeler article.
