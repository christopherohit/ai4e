# glass-lab

Shared runtime for the animated foundational-ML explainers (gradient-descent, mini-batch-sgd, naive-bayes, svm,
bias-variance, regularization). Each chapter is a short scene with a timeline, subtitles that follow it, live metrics,
a transcript, controls and a data table.

- GlassLab.astro / glass.css: the dark "explainer video" chrome (screen, player, chapters, dock, footer).
- engine.ts: timeline, chapter switching, subtitles, controls binding, pointer events, render loop.
- gfx.ts: canvas drawing kit: glow lines, glass panels, 2D plots with heat fields and contours, orbit camera and shaded 3D surfaces.
- regression.ts / views.ts: two-parameter least squares and the loss-map / trail / chart views used by the optimization labs.
- data/auto-mpg.json: shared by the gradient-descent and bias-variance labs.

All datasets are generated by scripts/ml-datasets/prepare.py from public sources and checked against scikit-learn.
