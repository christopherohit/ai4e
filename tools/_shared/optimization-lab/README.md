# optimization-lab

Shared code for the optimization explainers (gradient-descent-explainer, mini-batch-sgd-explainer).

- model.ts: 64 synthetic samples, MSE loss and gradient, closed-form optimum, level sets, seeded mini-batch training and gradient-noise formula.
- plots.ts / plots.css: SVG frame, contour map, data scatter, curves and arrows, styled with the sequence-lab colour roles.

The lab chrome (steps, step card, controls, chart) comes from tools/_shared/sequence-lab/.
