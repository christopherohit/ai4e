# gradient-descent-explainer

Animated explainer of gradient descent on real data: Auto MPG (mpg from car weight). Four chapters: fit a line to 392
cars, roll down the 3D loss surface, compare learning rates against the 2/λ_max threshold, and standardize the feature.
Article content stays in blog/src/content/posts/.

- Tool.astro: entry imported by the blog adapter (chrome from tools/_shared/glass-lab/).
- model.ts: the dataset in raw and standardized units, starting point and presets.
- render.ts: the four animated scenes.
- Data: tools/_shared/glass-lab/data/auto-mpg.json, generated by scripts/ml-datasets/prepare.py.

Every number shown is computed in the browser from the 392 cars; tests live in blog/tests/unit/glass-labs.test.ts.
