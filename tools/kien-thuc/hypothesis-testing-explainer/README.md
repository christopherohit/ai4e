# hypothesis-testing-explainer

Glass lab (tools/_shared/glass-lab) for the article in blog/src/content/posts/kien-thuc/nen-tang/.
Data: `data/` generated by `scripts/ml-datasets/prepare_stats.py` (see the script docstring for sources).
Files: Tool.astro (chrome + controls), model.ts (data and maths), render.ts (six animated chapters).
All p-values are recomputed in model.ts (t, normal, χ² tails) and checked against SciPy in blog/tests/unit/ml-foundation-labs.test.ts.
