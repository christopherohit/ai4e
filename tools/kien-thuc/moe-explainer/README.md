# moe-explainer

Glass lab (tools/_shared/glass-lab) for the article in blog/src/content/posts/kien-thuc/toi-uu-llm/.
Data: `data/` generated by `scripts/llm-bake/moe.py` (see the script docstring for sources).
Files: Tool.astro (chrome + controls), model.ts (data and maths), render.ts (five animated chapters).
Educational simulation: a small MoE trained on handwritten digits, not a pretrained LLM. Published model sizes in model.ts come from the model cards.
