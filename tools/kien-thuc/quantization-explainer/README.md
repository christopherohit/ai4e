# quantization-explainer

Glass lab (tools/_shared/glass-lab) for the article in blog/src/content/posts/kien-thuc/toi-uu-llm/.
Data: `data/` generated by `scripts/llm-bake/quantize.py` (see the script docstring for sources).
Files: Tool.astro (chrome + controls), model.ts (data and maths), render.ts (five animated chapters).
Perplexities and answers are real measurements of Qwen2.5-0.5B-Instruct quantized with round-to-nearest (quantize → dequantize on CPU).
