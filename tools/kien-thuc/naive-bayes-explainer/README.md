# naive-bayes-explainer

Animated explainer of Multinomial Naive Bayes trained on the SMS Spam Collection: counting words, the likelihood map
of 3 672 words, a token-by-token evidence waterfall for any message, and real test-set results with calibration.
Article content stays in blog/src/content/posts/.

- Tool.astro: entry imported by the blog adapter (chrome from tools/_shared/glass-lab/).
- model.ts: tokenizer, smoothed likelihoods and the evidence computation.
- render.ts: the four animated scenes.
- data/sms-spam.json: word counts and test metrics generated by scripts/ml-datasets/prepare.py (no message texts).
