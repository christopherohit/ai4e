# mini-batch-sgd-explainer

Animated explainer comparing batch gradient descent, mini-batch gradient descent and SGD on real data: California
Housing (median house value from median income, all 20 640 block groups). Four chapters: batch GD, SGD sample by sample,
the mini-batch noise fan with an exact noise formula, and a race with an equal gradient budget.
Article content stays in blog/src/content/posts/.

- Tool.astro: entry imported by the blog adapter (chrome from tools/_shared/glass-lab/).
- model.ts: the dataset, seeded shuffles, training loop and gradient-noise formula.
- render.ts: the four animated scenes.
- data/california-housing.json: generated by scripts/ml-datasets/prepare.py.
